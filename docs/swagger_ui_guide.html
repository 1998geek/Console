🔐 Swagger UI 认证指南

Authentication Guide for Swagger UI

❌ 常见问题 / Common Problem

中文: 登录成功后，访问 /api/v1/auth/me 返回 403 Forbidden

English: After successful login, /api/v1/auth/me returns 403 Forbidden

✅ 解决方案 / Solution

中文: 您必须点击 Swagger UI 页面右上角的 "Authorize" 按钮 🔓，并在弹出窗口中输入您的 access token。

English: You MUST click the "Authorize" button 🔓 at the top right of Swagger UI and enter your access token in the popup.

📍 找到 Authorize 按钮 / Find the Authorize Button

中文: 在 Swagger UI 页面的右上角，查找带有锁图标 🔓 的 "Authorize" 按钮
English: Look for the "Authorize" button with lock icon 🔓 at the top right corner of Swagger UI

🔓 Authorize

⬆️ 点击这个按钮 / Click this button ⬆️

📝 完整步骤 / Complete Steps

1

登录获取 Token / Login to Get Token

中文: 找到并执行 POST /api/v1/auth/login 接口

English: Find and execute POST /api/v1/auth/login

👑 管理员 / Admin

Username: admin

Password: admin123

👤 普通用户 / User

Username: user

Password: user123

2

复制 Access Token

中文: 从登录响应中复制 access_token 的值（很长的字符串）

English: Copy the access_token value from login response (long string)

{ "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", <-- 复制这个 / Copy this "refresh_token": "...", "token_type": "bearer" }
3

🔓 点击 Authorize 按钮 / Click Authorize Button

中文: 这是最关键的一步！ 在 Swagger UI 页面右上角找到 "Authorize" 按钮并点击

English: This is the critical step! Find and click the "Authorize" button at top right

4

输入 Token / Enter Token

中文: 在弹出的对话框中，将复制的 token 粘贴到 "Value" 输入框中

English: In the popup dialog, paste your token into the "Value" input field

Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... 或者直接粘贴 token (不带 Bearer 前缀也可以): eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
5

授权并关闭 / Authorize and Close

中文: 点击 "Authorize" 按钮，然后点击 "Close" 关闭对话框

English: Click "Authorize" button, then click "Close" to close the dialog

⚠️ 注意: 锁图标应该从 🔓 变为 🔒

6

✅ 测试认证接口 / Test Authenticated Endpoints

中文: 现在您可以成功调用需要认证的接口了：

English: Now you can successfully call authenticated endpoints:

  • GET /api/v1/auth/me - 获取当前用户信息 / Get current user info
  • POST /api/v1/auth/logout - 退出登录 / Logout
  • POST /api/v1/translate/text - 文本翻译 / Text translation
  • 其他所有需要认证的接口 / All other protected endpoints

💡 为什么会这样？ / Why This Happens?

中文: Swagger UI 需要通过 "Authorize" 按钮来配置全局的认证信息。仅在单个请求中添加 Authorization header 是不够的。

English: Swagger UI needs the "Authorize" button to configure global authentication. Simply adding Authorization header in individual requests is not sufficient.

🚀 快速访问 / Quick Access

📖 打开 Swagger UI / Open Swagger UI 🔑 直接跳转到登录接口 / Go to Login Endpoint

🐍 Python 测试脚本 / Python Test Script

如果您想验证 API 是否正常工作，可以运行测试脚本：

To verify the API works correctly, run the test script:

cd /home/user/webapp python test_auth.py

✅ 这个脚本会自动测试登录、/me 和 /logout 接口

✅ This script automatically tests login, /me and /logout endpoints
